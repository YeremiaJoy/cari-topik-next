# Illustrations

Drop flat vector illustrations here as `<name>.svg`. The `<Illustration>` component
renders `/illustrations/<name>.svg` and shows a styled placeholder until the file exists —
so you can add art at any time with zero code changes.

Expected files (guest + app flow redesign):

| File | Used on | Suggested subject |
| ---- | ------- | ----------------- |
| `hero-conversation.jpg` | Landing hero | Four people playing cards (Stitch raster; loaded via `ext="jpg"`) |
| `category-couple.svg` | Landing "for who" | Couple, warm |
| `category-friends.svg` | Landing "for who" | Group of friends |
| `category-family.svg` | Landing "for who" | Family across generations |
| `paywall-connection.svg` | Paywall modal | Two people talking, locked-heart above |

Style: modern-minimalist, thick friendly line art. Palette — espresso brown
(`#241509`), primary orange (`#f47521`), soft cream (`#fff8f2`).
